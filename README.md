# Zhibo Wang Engineering Portfolio

Personal portfolio for Zhibo Wang, a Computer Engineering student at UC San Diego. The site presents embedded systems, TinyML, FPGA, VLSI, power electronics, performance engineering, image processing, and software projects as concise case studies.

## Highlights

- Data-driven project pages generated from one structured project collection
- Responsive, accessible layouts with semantic HTML
- System, light, and dark themes with saved preferences
- Static full-site search through Pagefind
- Downloadable and embedded resume
- Netlify contact form and deployment configuration

## Local development

```bash
npm install
npm run dev
```

Create the production build:

```bash
npm run build
```

The generated site is written to `_site/`.
